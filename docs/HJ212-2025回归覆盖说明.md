# HJ212—2025 字段与附录 C 回归覆盖

本项目约定的 HJ 212—2025 编解码适配、字段细节、附录 C 全部命令样例回归和接口一致性工作已完成。本报告记录实际覆盖与验证边界，不表示全面合规或厂商设备互操作认证。

项目总览见 [README](../README.md)，接口见 [编解码使用说明](HJ212-2025编解码使用说明.md)，修复清单见 [修复说明](HJ212-2025修复说明.md)。

## 已完成

- 对表 5 的 N 型原始整数位数和小数精度进行校验；前导零计入宽度，不能先转数值再判断。
- 检查长度与 CRC 字段各自的四位十进制/十六进制字符集，不接受加号等替代字符。
- 完成附录 C.1～C.63 的全部 188 条请求、上传和应答正文回归。
- 对 Data、扁平 Map、深层 Map、Pack 及加密入口验证字段值；覆盖 String、byte[]、Reader、InputStream 及输出接口。
- 修复扁平 Map 输出丢失 CP 的 &&、只含 RT 时 Data 往返凭空增加 RS=0 的问题；旧 getRs()/setRs(int) API 保留，可通过 hasRs()/getRsValue() 区分缺失。
- 支持日志 // 引号内的中文、空格、分号、逗号、等号和 &&；检查闭合引号及小于 890 字节的限制。
- 为污染因子关联的 SampleType 补充强类型属性和校验。

## 原文及规范化原则

来源：[生态环境部正式标准 PDF](https://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/jcffbz/202507/W020250711505311328432.pdf)。源文件 SHA-256：`ed5e46fc1cf5dc99ace6878a5d347f4c0269b818052f3774c9708cf60a74e506`。

附录 C 给出的是数据段正文，测试用独立实现按附录 A.1 计算长度和 CRC 组包，避免以被测编码器生成全部输入。预期字段和值从固定样例独立拆解；Pack 另要求字节正文保持原样。

188 条中，165 条仅整理 PDF 排版折行和空白；23 条含“…”或“......”，必须移除表示继续列举的省略标记及其空项目才能构成可发送报文。本轮同时保留 source 和 normalized 两列，并对带原文省略标记的输入明确断言拒绝，未编造任何被省略的字段或数值。真实日志空格不经过这种 PDF 整理，另有保真测试。

固定数据在 `protocol/src/test/resources/hj212-2025/appendix-c.json`，边界矩阵在 `field-boundaries.json`。无需下载 PDF 或安装 Python 即可运行 Java 回归。

## 范围说明

上述“完成”指本轮明确约定的字段细节、附录 C 全部命令样例与接口一致性工作。它不扩展为设备会话、密钥生命周期或数据库能力，也不等同于设备互操作认证。标准存在 A/D 文字与数值示例不一致、SN 字符集与示例不一致等情况，继续遵循数值/命令样例并在可扩充字段上保留兼容。

已知字符型工况采用附录 B 的 C3/C4/C6 宽度；未发布的扩充编码不作封闭白名单。日志长度按含 // 的传输值计。

执行环境为 OpenJDK 17、Maven 3.10.0，尚未在 Java 8 运行时验证。复现：在项目根目录执行 `mvn test`。
